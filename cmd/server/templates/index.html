curl 기반 텍스트/로그 공유 서비스

curl을 사용하여 텍스트나 로그를 업로드하면 5자리의 무작위 URL이 생성됩니다. 생성된 임시 링크는 30일 후에 자동으로 삭제됩니다.

텍스트 업로드 echo "hello" | curl --data-binary @- {{ .BaseURL }}
명령어 출력 업로드 ifconfig | curl --data-binary @- {{ .BaseURL }}
텍스트 파일 업로드 curl -v --data-binary @test.txt {{ .BaseURL }}
비밀번호 보호 (무작위 발급) curl --data-binary @secret.txt {{ .BaseURL }}/pw
비밀번호 직접 지정 (정책 조합 가능) curl --data-binary @secret.txt {{ .BaseURL }}/pw/12345 curl --data-binary @secret.txt {{ .BaseURL }}/pw/12345/week
비밀번호 헤더 지정 (URL 노출 방지) curl -H "custom-pw: 12345" --data-binary @secret.txt {{ .BaseURL }}/week
1회 열람 후 파기 ifconfig | curl --data-binary @- {{ .BaseURL }}/temp
1주 보관 후 자동 삭제 ifconfig | curl --data-binary @- {{ .BaseURL }}/week
만료 정보 주소: {{ .BaseURL }}/AbC12 만료일: 2026-06-24T05:10:26Z 삭제링크: {{ .BaseURL }}/AbC12?delete=DELETE_TOKEN
수동 삭제 curl "{{ .BaseURL }}/AbC12?delete=DELETE_TOKEN"
